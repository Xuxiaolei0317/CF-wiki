成就数据生成工具

ACHIEVEMENT_MISSION_CONFIG 是当前所有阈值；粘贴当前 achievement_progress_data 后，可基于现有数据批量修改指定任务值。

生成参数

只影响 achievement_progress_data 和“全部数据”中的当前进度。当前数据为空时，会自动从 0 开始。

支持直接粘贴数组，或粘贴「achievement_progress_data = [...]」。工具会在这份数据基础上修改，不会重置其他任务。

每行一个任务，格式为「任务编号=进度」。支持 K/M/B/T/Q 后缀，也支持金币、VIP 和段位文本解析。
